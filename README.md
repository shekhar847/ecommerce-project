# ShopSphere - MERN E-Commerce Platform

## Features

* User Authentication (Login/Register)
* Product CRUD Operations
* Product Search & Filters
* Cart Management
* Wishlist
* Product Reviews & Ratings
* Checkout & Orders
* Payment Gateway Integration
* Admin Dashboard
* Revenue Analytics
* Order Tracking
* Responsive Design
* Toast Notifications

## Tech Stack

### Frontend

* React.js
* React Router
* Bootstrap
* Context API
* Axios

### Backend

* Node.js
* Express.js

### Database

* MongoDB

## Installation

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
